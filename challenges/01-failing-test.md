# Challenge 1: Failing test (about 10 minutes)

CI on `main` has gone red. Nobody has changed the tests recently.

```bash
uv run pytest
```

## Your task

1. Find out why the tests fail and when it started.
2. Fix the cause. Don't change the tests to make them pass unless you can explain why the
   test is wrong.
3. Be ready to explain the root cause and how you made sure the fix is complete.

When you're done, all checks in `AGENTS.md` should pass.
